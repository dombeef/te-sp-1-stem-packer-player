help

packing stems

  1. load audio. drop files anywhere on the page, press import, or use + add on a single stem. wav, mp3, aiff, flac and most other formats work.
  2. arrange. each column is one stem. files in the same column are mixed together. drag a file to another column, or change the number next to it.
  3. check it. press play and move the faders to hear the balance.
  4. export. enter a name and an optional bpm (added to the filename, e.g. song_120bpm.wav), then press build wav.
  5. load it onto your sp-1 with the stem loader at solderless.engineering. it runs in desktop chrome or edge.

the result is one signed 24-bit, 48 khz, 8-channel wav:

stem 1ch 1 / 2
stem 2ch 3 / 4
stem 3ch 5 / 6
stem 4ch 7 / 8

mp3 and mono files become stereo, and everything is resampled to 48 khz. all stems start at 0:00. shorter stems are padded with silence.

playing stems

import or drop an 8-channel stem file and it splits back into its four stems. the name and bpm are read from the filename.

  • play / pause: the orange button, or space.
  • move through the song: drag the line.
  • faders: drag a knob, or tap the slot to jump there. double-click resets to full.
  • keys: hold one to hear only that stem. hold several to hear just those.
  • lights: on while that stem is making sound.

good to know

  • faders and keys only change the preview. the exported file is always full level.
  • prevent clipping turns a stem down only when mixing files pushes it over 0 dbfs.
  • everything runs in your browser. nothing is uploaded.
  • on iphone, turn off silent mode to hear the preview.
